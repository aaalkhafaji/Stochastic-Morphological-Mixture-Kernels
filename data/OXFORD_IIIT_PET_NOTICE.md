# Oxford-IIIT Pet external-data notice

The Step-5 campaign uses the **official Oxford-IIIT Pet annotation archive** as an external dependency. It is not redistributed in this repository.

- Dataset page: https://www.robots.ox.ac.uk/~vgg/data/pets/
- Annotation archive: https://www.robots.ox.ac.uk/~vgg/data/pets/data/annotations.tar.gz
- Expected MD5: `95a8c909bbe2e81eed6a22bccdf3f68f`
- Dataset paper: O. M. Parkhi, A. Vedaldi, A. Zisserman, C. V. Jawahar, “Cats and Dogs,” CVPR, 2012.
- License stated by the dataset host: Creative Commons Attribution-ShareAlike 4.0 International; copyright remains with original image owners.

The quantitative Step-5 code uses trimap annotations only; the RGB image archive is not needed.
